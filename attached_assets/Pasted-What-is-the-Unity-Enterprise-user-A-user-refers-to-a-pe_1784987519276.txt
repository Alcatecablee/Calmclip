What is the Unity Enterprise user? A user refers to a person who will have access to Unity Enterprise, distinct from employees who will only have access to the point of sale within the Unity software. Creating users is a task that can only be performed within the admin node, and thus requires a user with admin node access. To access the user's feature, simply navigate to the organization section, then the user's section. The displayed screen will show you all the users currently loaded on the organization. It will provide quick information for example, Last name, contact number, as well as if the user is active or not. Need to make changes to a current user's profile? Click on the pencil icon next to the user details on the grid to enter the profile and make any changes as needed. Remember to save once changes have been made.
